# AI Knowledge Assistance System

An AI-powered document-based question answering system built using **FastAPI**.  
Users can upload documents, index them, and ask questions to retrieve relevant answers with confidence scores.

---

## 🚀 Features

- Upload documents via API
- Automatically index documents
- Ask natural language questions
- Get answers with confidence score
- FastAPI backend with Swagger UI
- Clean modular code structure
- Ready for deployment

---

## 🛠 Tech Stack

- Python 3.10+
- FastAPI
- Uvicorn
- Scikit-learn
- NumPy
- Pandas
- python-multipart
- dotenv
